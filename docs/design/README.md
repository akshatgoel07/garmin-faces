# Design

`fitted-design-sheet.html` is the design sheet for the first face. Open it in a browser. It draws five variants at the Forerunner 965's 454 px, switches between typefaces and accents, and measures the always-on pixel load against Garmin's 10% cap.

Decisions land here once made, one file per face.

`trio-chrono-design-sheet.html` is the sheet for the second face, a chronograph dial copied from a reference photo. It shows the black and white dials and the always-on fallback at 454 px with live hands, lists the layout numbers the renderer and the Monkey C view share, and measures the always-on pixel load.
